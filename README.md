# Мини-графический редактор

## 1. Название и описание задачи

Программа представляет собой мини-графический редактор, который позволяет создавать геометрические фигуры (круги и квадраты), просматривать их характеристики и вычислять общую площадь всех фигур.

Программа демонстрирует три основных принципа объектно-ориентированного программирования:
- Инкапсуляцию — скрытие внутренних данных и доступ к ним через методы
- Наследование — создание дочерних классов от базового
- Полиморфизм — единый интерфейс для разных типов фигур

## 2. Архитектура проекта

### Инкапсуляция
В базовом классе Figure координаты _x и _y являются приватными. Доступ к ним осуществляется только через публичные методы:
- get_coords() — получить координаты
- set_coords(x, y) — изменить координаты
  Это защищает внутренние данные от случайного или некорректного изменения извне.

### Наследование
Создана иерархия классов:
```
Figure (базовый класс)
├── Circle (дочерний класс)
└── Square (дочерний класс)
```
Дочерние классы наследуют от Figure координаты и методы работы с ними, добавляя свои уникальные свойства:
- Circle — радиус (radius)
- Square — сторона (side)

### Полиморфизм
В каждом дочернем классе переопределён метод calculate_area():
- В Circle — площадь круга: π * r²
- В Square — площадь квадрата: a²

Благодаря полиморфизму, в главной программе можно единообразно вызывать метод calculate_area() для любой фигуры, не проверяя её тип.

## 3. Пример использования

# Создание фигур
```
circle = Circle(0, 0, 5)
square = Square(10, 10, 4)
```
# Получение координат
coords = circle.get_coords()  # (0, 0)

# Расчёт площади
```
circle_area = circle.calculate_area()  # 78.54
square_area = square.calculate_area()  # 16.0
```
# Список фигур и подсчёт общей площади
```
figures = [circle, square]
total = 0
for fig in figures:
    total += fig.calculate_area()
print(f"Общая площадь: {total:.2f}")
```
