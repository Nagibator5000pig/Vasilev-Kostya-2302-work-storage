# Мини-графический редактор

## 1. Название и описание задачи

Программа «Мини-графический редактор» демонстрирует три основных принципа
объектно-ориентированного программирования (ООП) на примере геометрических фигур.

Программа позволяет:
- создавать круги (`Circle`) и квадраты (`Square`);
- задавать фигурам координаты и размеры;
- вычислять площадь каждой фигуры;
- считать общую площадь всех созданных фигур.

## 2. Архитектура проекта

### Инкапсуляция

В базовом классе `Figure` координаты хранятся в защищённом атрибуте `_coords`.
Напрямую снаружи к нему обращаться не рекомендуется — это внутренние данные класса.

Доступ к координатам осуществляется только через публичные методы:
- `get_coords()` — возвращает текущие координаты (кортеж);
- `set_coords(coords)` — устанавливает новые координаты.

Это защищает данные от случайного изменения извне.

### Наследование

Создана иерархия классов:

```
Figure (базовый класс)
├── Circle (дочерний класс)
└── Square (дочерний класс)
```

Дочерние классы наследуют от `Figure` атрибут `_coords` и методы
`get_coords()` / `set_coords()`, а также добавляют свои уникальные свойства:

- `Circle` — `radius` (радиус);
- `Square` — `side` (сторона).

### Полиморфизм

В каждом дочернем классе реализован метод `calculate_area()`:

- в `Circle` — площадь круга: `π * r²` (используется `math.pi`);
- в `Square` — площадь квадрата: `side²`.

Благодаря полиморфизму в главной программе можно одним циклом обойти
список фигур и вызвать `calculate_area()` у каждой — **не проверяя её тип**.
Python сам вызовет нужную версию метода.

## 3. Пример использования

```python
# Создание круга
c1 = Circle()
c1.radius = 2
c1.set_coords((0, 0))

# Создание квадрата
s1 = Square()
s1.side = 4
s1.set_coords((2, 2))

# Список фигур и подсчёт общей площади
figures = [c1, s1]
total_area = 0
for f in figures:
    total_area += f.calculate_area()

print(f"Общая площадь всех фигур: {total_area}")
```

## 4. Результат работы

При запуске программы в консоль выводится общая площадь всех фигур.

Пример вывода для двух фигур (круг с радиусом 2 и квадрат со стороной 4):

```
Общая площадь всех фигур: 28.566370614359172
```

Если взять набор из задачи (2 круга и 3 квадрата), результат будет:

```
Общая площадь всех фигур: 192.8407044966673
```
